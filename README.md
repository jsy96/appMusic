# appMusic

一个纯前端网页应用，用于选择不同情感词，基于 `tension` 和 `brightness` 两个浮点参数自动匹配和弦进行，生成简谱音级，并通过浏览器 Web Audio API 连续演奏。

## 功能

- 情感词选择：内置 24 种情感词，每种情感包含 `tension` 和 `brightness` 两个 0～1 浮点参数。
- 自动和弦匹配：内置 26 组和弦搭配库，系统会根据情感参数选择最接近的和弦进行。
- 选择根音 / 调性：支持 C 到 B 的 12 个半音，情感和弦进行会自动按所选根音移调。
- 手动和弦选择：支持大三、小三、减三、增三、sus2、sus4、属七、大七、小七、半减七、六、小六、九、add9、maj9、m9、7b9、7#5、maj7#11、dim7、mMaj7 等和弦。
- 进行 → 手动联动：在「情感和弦进行」中点击任一和弦名，会自动把该和弦的根音与和弦类型同步到「根音 / 调性」和「手动和弦类型」两个下拉，载入到「当前和弦」并试听一声；随后即可用「播放当前和弦 / 琶音」在该和弦上单独探索或修改（情感进行显示保持不变）。
- 输出简谱：当前和弦和情感和弦进行都会显示对应简谱音级，播放时会实时显示并高亮当前播放到的简谱音。
- 播放声音：支持播放当前和弦（整块齐奏）、当前和弦琶音（逐音依次响）、完整情感和弦进行；每次点击播放后会自动重复播放，并在 30 秒后停止。
- 情感进行采用和弦式齐奏：每个和弦的所有音同时发声（与「播放当前和弦」一致），每个音的延续时长由「情感和弦进行」卡片内的「每音时长」滑块独立控制（80–800 ms，默认 300 ms），和弦之间额外留 0.2 s 间隔。该滑块只作用于情感进行；「琶音时长」滑块只负责「播放当前和弦琶音」的逐音间隔，两者互不影响。
- 调整琶音时长：可通过滑块调整当前和弦琶音的每个音间隔。
- 实例片段：每个情感和弦进行配 1~3 个使用了相似进行或类似色彩的真实音乐作品作为参考，并可点击「演奏示范」用 Web Audio 合成一段贴合该进行的原创示范旋律（旋律声 + 柔和和弦垫），旋律简谱会随播放实时高亮。示范旋律根据和弦根音 + 旋律风格（抒情慢板 / 跳跃活泼 / 流动连贯 / 紧张半音）从和弦音派生，纯原创、不引用具体歌曲旋律；切换根音/调性时旋律会自动移调。

## 使用方式

**Windows 一键启动**：双击 `start.bat`，或在 cmd 里运行：

```bat
start.bat
```

脚本会自动定位项目目录、用 uv 启动本地静态服务器（默认端口 8000），并在 2 秒后用默认浏览器打开页面。需要指定端口时传入参数：

```bat
start.bat 9000
```

停止服务器：在命令行窗口按 `Ctrl+C`。脚本依赖本机已安装的 [uv](https://docs.astral.sh/uv/)（若未安装会提示并退出）。

**手动启动**：也可以直接用浏览器打开 `index.html`，或在项目目录自行启动静态文件服务器：

```bash
uv run --no-project -m http.server 8000
```

然后在浏览器访问 `http://localhost:8000`。

## 情感参数逻辑

- `brightness` 越高，越倾向于明亮、开放的和弦色彩，例如 major、6、add9、maj7、maj9。
- `brightness` 越低，越倾向于阴暗、低沉的和弦色彩，例如 minor、m7、m6、m7b5、dim。
- `tension` 越高，越倾向于紧张、不稳定的和弦色彩，例如 sus4、7、9、7b9、7#5、dim7。
- `tension` 越低，越倾向于稳定、舒展的和弦色彩，例如 major、6、add9、maj7。

## 界面设计

- 整体风格：深邃午夜底色 + 缓慢流动的彩色光斑，金 / 品红 / 紫三色渐变作为强调色，所有面板使用毛玻璃（backdrop-filter）效果。
- 自上而下的操作顺序：页面按「选择 → 生成 → 播放 → 查阅」线性排列，「当前和弦」卡片标题前带 `02` 步骤徽章（对应 Hero 流程指引的第 2 步），Hero 顶部还有一条三步流程指引，让操作顺序一目了然。
- 就近播放按钮：播放按钮与它控制的对象放在一起——「播放当前和弦 / 播放当前和弦琶音 / 停止」在「当前和弦」卡片内；「情感和弦进行」卡片内含独立的「每音时长」滑块 + 「播放情感进行」+「停止」（停止位于播放按钮右侧，随时中断）。
- 就近参数控件：参数控件与它控制的对象放在一起——「情感词」在「情感和弦进行」卡片内（决定进行），「手动和弦类型」+「琶音时长」在「当前和弦」卡片内（决定当前和弦与琶音）；全局的「根音 / 调性」放在 Hero 顶部（决定全局调性，同时影响下方两个卡片）。
- 渐变标题：Hero 大标题与「当前和弦」的和弦名都用渐变色文字呈现。
- 自定义控件：下拉框使用自定义箭头，琶音时长滑块的轨道会按当前值实时填充金→品红渐变进度。
- 参数可视化：每个情感词卡片和当前情感统计区都会用迷你进度条分别显示 `tension`（金→玫红）和 `brightness`（靛→青）两个参数的强弱。
- 播放反馈：进入播放时 `<body>` 会加上 `is-playing` 类标记状态；和弦齐奏（播放当前和弦 / 情感进行里的每个和弦）时，对应卡片里该和弦的所有简谱音会同时高亮，与同时发声的声音保持同步；琶音与示范旋律则保持逐音高亮。
- 简谱音符：每个简谱音是独立胶囊，播放命中时会渐变高亮、上浮放大并发光。
- 实例片段卡片：每个示例显示作品名、相似进行说明、旋律风格标签，以及原创旋律的简谱（每个和弦小节之间用「|」分隔，方便看清每个节奏；带八度点，高音上方加圆点、低音下方加圆点），播放时当前音渐变高亮上浮。
- 参考资料 grouping：底部三个静态清单（情感词参数 / 和弦搭配库 / 已支持和弦）统一归入「参考资料」组标题之下，作为查阅区与上方交互区清晰分隔。
- 响应式：980px 以下控件改两列、网格改单列；720px 以下 Hero、控件、页脚全部纵向堆叠。同时遵循 `prefers-reduced-motion`，关闭光斑动画。

## 技术说明

- 页面不依赖构建工具或第三方前端框架。
- 声音播放使用浏览器内置的 Web Audio API。
- 首次播放需要由用户点击按钮触发，这是现代浏览器对音频自动播放的限制。
